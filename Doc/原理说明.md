# 底层原理说明

## 1. 电机为什么会转

两个磁场之间有夹角，就会产生转矩：

\[
T = C_t \Phi I \sin\theta
\]

- \(C_t\)：电机结构常数
- \(\Phi\)：定子磁场磁通
- \(I\)：电枢电流
- \(\theta\)：定子磁场与转子磁场的夹角

当 \(\theta = 90^\circ\) 时，\(\sin 90^\circ = 1\)，转矩最大。

当 \(\theta = 0^\circ\) 或 \(180^\circ\) 时，\(\sin\theta = 0\)，转矩为零，这是死点。

---

## 2. 安培力中的 sinα 从哪来

单根导线在磁场中受力：

\[
F = BIL\sin\alpha
\]

\(\alpha\) 是**电流方向与磁场方向**的夹角。

- \(\alpha = 90^\circ\)：导线垂直于磁场，力最大；
- \(\alpha = 0^\circ\)：导线平行于磁场，不受力。

线框模型中，两条有效边电流方向相反，受力方向相反，形成力偶，产生转矩。

当线框磁场与定子磁场夹角为 \(\theta\) 时，转矩：

\[
T = BIA\sin\theta
\]

---

## 3. 有刷电机怎么保持 90°

换向器在转子磁场即将对齐定子磁场（\(\theta \to 0^\circ\)）时，把线框中的电流反向。

电流反向 → 线框磁场翻转 180°。

于是两个磁场永远不真正对齐，平均保持在 90° 附近。

所以教材里写 \(T = C_t \Phi I\)，因为默认 \(\sin\theta = 1\)。

---

## 4. BLDC 六步换相怎么做

BLDC 把线框搬到定子，转子变成永磁体。

- **定子磁场**：三相绕组产生，六步换相让它每 60° 电角度跳变一次；
- **转子磁场**：永磁体，连续旋转。

夹角变化：

```text
刚换相：120°
转子追：120° → 逐渐减小
到 60°：控制器换相
定子跳 60°：夹角瞬间回到 120°
