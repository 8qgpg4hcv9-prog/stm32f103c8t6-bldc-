# 调试记录

记录从零搭建 BLDC 六步换相驱动器，到实现速度环 PID 闭环的完整过程。按问题现象、排查过程、解决方案和工程收获进行整理。

## 一、 六步换相跑通

### 1.1 硬件搭建与引脚定义

主控：STM32F103C8T6；驱动板：ATK-PB6010B；电机：24V 带霍尔 BLDC。

*注：具体的引脚分配详见 [引脚定义.md](引脚定义.md)。*

关键配置：TIM1 互补 PWM 输出（PSC=71, ARR=99，频率 10kHz，死区约 1μs）。霍尔引脚配置为双边沿外部中断，根据霍尔状态查表换相。

# 1.2 问题二：PWM 利用示波器测试板子mos管无输出
现象：代码烧录后，MOS 管无驱动信号
排查过程：用示波器测量，板子上的mos管，上桥无信号，下桥信号正常，利用万用表测试从stm32引脚，到mos管的路径，最后发现是最小驱动板和面包板接触不良
解决方案：重新插紧stm32最小驱动板
收获：在排查问题时，要软件硬件分开排查
示波器收到正确波形
![互补PWM输出波形](Doc/up_mospwm.jpg)

**解决方案**：重新测量霍尔状态变化顺序，调整换相表中的对应关系，确认六个有效状态为 `0x05, 0x01, 0x03, 0x02, 0x06, 0x04`。

**收获**：不同厂家的电机，霍尔安装方向不同，换相表必须根据实测调整，不能照搬。

### 1.3 问题二：PWM 无输出

**现象**：代码烧录后，MOS 管无驱动信号，电机不转。

**排查过程**：用示波器测量 PA8，无波形。检查代码发现 `TIM_CtrlPWMOutputs(TIM1, ENABLE)` 被注释掉了。

**解决方案**：在 main 函数中使能 TIM1 主输出（MOE 位）。

**收获**：TIM1 作为高级定时器，必须使能主输出（MOE）才能输出 PWM。普通定时器不需要这一步，MOE 位类似于总电闸。

## 二、 换相优化：过流保护（OC）排查

### 2.1 高占空比触发过流保护

**现象**：占空比只能调节到 50% 左右，再高就会触发驱动板的过流保护，电机停机。

**初步怀疑**：换相时“先全关，再全开”导致绕组电感强制断流，产生高压尖峰，叠加工作电流后触发 OC 阈值。

**验证方法**：用示波器抓取相电压波形，确认换相瞬间存在明显的负向尖峰。

![相电压负压尖峰](此处替换为你的相电压波形图片链接)

*图：相电压波形，Vmin ≈ -2.00V，由电感续流产生。*

**第一次解决方案**：改变换相策略。
- 原策略：先关闭所有桥臂，再打开新的桥臂。
- 新策略：每次换相只切换一个桥臂，保持另一相导通。
- 效果：触发阈值从 50% 提升到 78%。

### 2.2 问题根源：主循环阻塞导致换相延迟

**现象**：即使优化了换相策略，78% 以上仍然触发 OC。

**排查过程**：
1. 检查主循环代码，发现 OLED 刷新（I2C 通信）和按键扫描存在阻塞式延时。
2. 主循环被拖慢后，换相逻辑响应不及时，电流异常飙升。

**解决方案**：
1. 按键：改为非阻塞状态机，去掉 `delay`。
2. OLED：改为分频刷新，每 500 次循环刷新一次。
3. 换相逻辑移入定时器中断，确保实时性。

**收获**：电机控制中，**实时性优先级最高**。主循环只处理“慢任务”（按键、显示、通信），快任务（换相、PID）必须放在中断里。
