# 1.1 问题一：PWM stm32引脚无输出
现象：代码烧录后，stm32引脚无驱动信号，电机不转。
排查过程：用示波器测量 PA8，无波形。检查代码发现 TIM_CtrlPWMOutputs(TIM1, ENABLE) 被注释掉了。
解决方案：在 main 函数中使能 TIM1 主输出（MOE 位）。
收获：TIM1 作为高级定时器，必须使能主输出（MOE）才能输出 PWM，普通定时器不需要这一步，然后两路输出类似分闸，而moe位类似于总闸。
# 1.2 问题二：PWM 利用示波器测试板子mos管无输出
现象：代码烧录后，MOS 管无驱动信号
排查过程：用示波器测量，板子上的mos管，上桥无信号，下桥信号正常，利用万用表测试从stm32引脚，到mos管的路径，最后发现是最小驱动板和面包板接触不良
解决方案：重新插紧stm32最小驱动板
收获：在排查问题时，要软件硬件分开排查
示波器收到正确波形
