
底层原理说明

1. 电机为什么会转

两个磁场之间有夹角，就会产生转矩：
由安培力公式开始，F=BILsina
推导出电磁转矩T=C_t Phi I sina;

- C_t：电机结构常数
- Phi：定子磁场磁通
- I：电枢电流
- a：定子磁场与转子磁场的夹角

当a=90度时转矩最大。

当定子磁场转子磁场平行时转矩为零，电机可能定在这里；


 2. 安培力中的 sinα 从哪来

单根导线在磁场中受力：

F = BIL\sin\a

a 是**电流方向与磁场方向**的夹角。

a=90导线垂直于磁场，力最大；
a=0或180导线平行于磁场，不受力。

线框模型中，两条有效边电流方向相反，受力方向相反，形成力偶，产生转矩。

当线框磁场与定子磁场夹角为 a 时，转矩：

T = BIA\sin\a


3. 有刷电机怎么保持 90°

换向器在转子磁场即将对齐定子磁场时，把线框中的电流反向。

电流反向 → 线框磁场翻转 180°。

于是两个磁场永远不真正对齐，平均保持在 90° 附近。

所以教材里写 (T = C_t Phi I)，因为默认 sina = 1。


 4. BLDC 六步换相怎么做

BLDC 把线框搬到定子，转子变成永磁体。

- 定子磁场：三相绕组产生，六步换相让它每 60° 电角度跳变一次；
- 转子磁场：永磁体，连续旋转。

夹角变化：
120~60 跳变120~60，让夹角平均值在90度保持扭矩
刚换相：120°
转子追：120° → 逐渐减小
到 60°：控制器换相
定子跳 60°：夹角瞬间回到 120°

5.为什么六步换相扭矩总是一直变化
由于定子磁场转子磁场夹角a一直在改变在60~120度之间
想要稳定只能上foc控制了

6.pwm调速原理
面积等效，电力电子技术中通过控制mos管通断，来控制平均电压，在惯性系统中成立

7. 互补 PWM 与死区
同一相的上下桥 MOS 管互补导通：

上桥导通 → 下桥关断
上桥关断 → 下桥导通
中间插入死区，防止直通短路
死区期间两个管子都关断，电流通过体二极管续流。

TIM1 硬件自动生成互补波形和死区，不需要软件手动切换。
