## 📖 项目简介

基于 STM32F103C8T6 与正点原子 ATK-PB6010B 驱动板，从底层物理逻辑出发，独立完成的三相无刷直流（BLDC）电机有感六步换相驱动器。

项目实现了从**开环调速**到**速度环 PID 闭环**的完整跨越，具备**带载抗扰动**能力（用手捏住电机，占空比自动补偿，松手转速自动恢复）。项目包含完整的原理推导、调试记录、示波器波形及上位机闭环响应曲线。

**核心亮点**：针对霍尔测速的量化误差引入了低通滤波算法，并彻底解决了主循环阻塞导致的换相延迟与 PID 控制周期不稳定问题。

- [x] 霍尔传感器有感六步换相（120° 导通方式）
- [x] TIM1 互补 PWM 输出 + 硬件死区配置
- [x] 开环正反转控制及能耗制动
- [x] 基于 EXTI 双边沿中断的霍尔测速（M法测速）

## 换相逻辑：由霍尔外部中断 (EXTI) 直接触发，确保换相时机不被主循环拖延。

## 控制周期：由 TIM2 硬件定时器硬性保证（10ms），不受主循环耗时任务（如 OLED 刷新、串口打印）影响。

## 🐛 核心问题排查（详情见 Doc/调试记录.md）
在开发过程中，解决了多个典型的嵌入式实时控制问题：
高占空比触发过流保护（OC）：
现象：占空比调至 50% 以上即触发硬件保护。
排查：示波器抓取相电压波形，确认换相瞬间存在 -2V 负压尖峰。
根本原因：最初换相采用“先全关再全开”，强制电感断流；且主循环中存在 OLED 阻塞，拖慢了换相响应速度。
解决：改为“每次只切一个桥臂”，并将换相逻辑移入 EXTI 中断，彻底解决。
串口打印导致 PID 闭环震荡：
现象：打开串口打印时 PID 稳定，关掉串口反而剧烈震荡。
根本原因：vsprintf 格式化浮点数极其耗时，阻塞主循环，意外拉长了 PID 的控制周期。关掉串口后周期缩短，原本合适的 Ki 变得过大。
解决：将 PID 计算移入 TIM2 定时中断，与主循环解耦；串口打印改为整数放大格式（%d，数值乘10）。
PID 不起作用（单位不匹配）：
现象：加入 PID 后转速不跟随目标值。
根本原因：目标值（旋钮刻度）与实际转速（RPS）物理量不统一，两者做减法的误差没有物理意义。
解决：统一量纲，将旋钮刻度线性映射到 0~50 RPS 目标转速。
