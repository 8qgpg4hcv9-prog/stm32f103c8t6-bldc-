# 引脚定义

## 主控：STM32F103C8T6

### BLDC 驱动板接口

| STM32 引脚 | 功能 | 连接 |
|---|---|---|
| PA0 | BLDC 使能 SHDN | 驱动板 SHDN |
| PA8 | TIM1_CH1 | U 相上桥 |
| PA9 | TIM1_CH2 | V 相上桥 |
| PA10 | TIM1_CH3 | W 相上桥 |
| PB13 | TIM1_CH1N | U 相下桥 |
| PB14 | TIM1_CH2N | V 相下桥 |
| PB15 | TIM1_CH3N | W 相下桥 |

### 霍尔传感器

| STM32 引脚 | 功能 |
|---|---|
| PA1 | HU |
| PA2 | HV |
| PA3 | HW |

### 编码器

| STM32 引脚 | 功能 |
|---|---|
| PA6 | TIM3_CH1（编码器 A 相） |
| PA7 | TIM3_CH2（编码器 B 相） |

### 按键

| STM32 引脚 | 功能 |
|---|---|
| PB1 | KEY1 停止 |
| PB10 | KEY2 正转 |
| PB11 | KEY3 反转 |

### OLED（调试用）

| STM32 引脚 | 功能 |
|---|---|
| PB8 | SCL |
| PB9 | SDA |

## 换相表

### 正转

| 霍尔状态 | 编码 | 导通相 |
|---|---|---|
| 101 | 0x05 | U+V- |
| 001 | 0x01 | U+W- |
| 011 | 0x03 | V+W- |
| 010 | 0x02 | V+U- |
| 110 | 0x06 | W+U- |
| 100 | 0x04 | W+V- |

### 反转

| 霍尔状态 | 编码 | 导通相 |
|---|---|---|
| 101 | 0x05 | U-V+ |
| 001 | 0x01 | U-W+ |
| 011 | 0x03 | V-W+ |
| 010 | 0x02 | V-U+ |
| 110 | 0x06 | W-U+ |
| 100 | 0x04 | W-V+ |
